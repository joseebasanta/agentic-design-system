# Semantic colors

Use a semantic custom property for the purpose the color serves. For example, set `color: var(--ads-color-text-strong-950)` for high emphasis text. See the repository README for token sources, mode attributes, and regeneration.

In Tailwind, use `text-ads-text-strong-950` for the same color or `bg-ads-bg-white-0` for the main surface. The preview below uses these classes and updates as you switch Figma modes.
