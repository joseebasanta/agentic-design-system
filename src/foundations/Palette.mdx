# Color palette

Use these raw values to define semantic colors. Components should use the semantic custom properties for surfaces, labels, borders, icons, and state colors.

The checkerboard behind translucent swatches shows how the underlying surface affects the result. The neutral alpha labels in the Figma frame are bound to the Slate alpha variables. Gray also has distinct 24% and 16% variables in the same collection.
