# Color palette

Use these raw values to define semantic colors. Components should use the semantic custom properties for surfaces, labels, borders, icons, and state colors.

The checkerboard behind translucent swatches shows how the underlying surface affects the result. The neutral alpha swatches in the Figma frame reference Slate. The variable collection also defines separate Gray alpha colors at 24%, 16%, and 10%.
